# Attribution and scope

`parent_l44/` is the unchanged user's L4.4 package, including historical L4.3/L4.2/L4.1 dependencies. All254 inherited member hashes are recorded. Parent evidence is historical, not newly executed L4.5 evidence. The new reference code imports actual inherited backbones/Cells and keeps their independent-reference status; it does not claim official reproduction of named neuron architectures.

The literature report credits established reconstruction, activation intervention, independent probing, spatial representation alignment, causal/streaming evaluation, linear algebra and risk methods. New adaptations and research contribution targets are described separately from foundations.

Nineteen inspected author text files from nine public repositories are fixed by commit, Git blob and SHA256 in `references/selected_author_sources.json`. Full external author source files and the private review clone are not redistributed. The fetcher retrieves only the exact public text files for limited audits. Consult each original repository's license before redistributing its source. No author weights, datasets, subjective studies or full paper reproductions are included.

Artificial single-token, zero-norm and state-fixture checks establish limited function contracts, not a conclusion that authors' normal experiments are invalid. Official code URLs that returned errors remain documented; forks are not relabeled as official.

Synthetic four-band data are generated by this package and are not claimed to be measurements from a real satellite/event/spike camera. Included initialization snapshots are the reference models' random untrained weights, with hashes matching the pre-evaluation contract.
