# 两阶段执行：第一阶段覆盖全部层级，第二阶段扩展条件与确认

日期：2026-10-31。状态：研究执行合同；不是已运行结果，也不是新的GPU耗时测量。

本计划修订“明天前只做36/72项和三个问题”的过窄方案。第一阶段仍优先重要结论和创新性分析，但六层的研究责任以及原小节均保留。优先级影响执行顺序、扩展范围及重复数量；不能用它删除一个分析层级，或以完成一个共同模块代替原专项协议。

## 1. 两个阶段怎样划分

第一阶段选择少量能同时支撑多层分析的任务、模型和检查点，完成跨层证据链。分类、重建、真实数据、学习形成都需要实际结果。原每个小节有明确分析动作、对照、产物和执行状态；没有执行的条目必须标为未完成或阻塞。明天的报告可呈现完整研究结构和已取得的证据，但不得称所有专项分析已完成。

第二阶段扩展数据、骨架、单元、负荷、时间尺度、种子及训练设置，执行独立确认并检查边界。继续复用全部合法旧结果。第一阶段已经完成的训练不因报告组织变化而重训。

此前72项及6–12小时估算不覆盖这个范围，不能继续作为完成承诺。必须先编译训练和后处理清单，核对已有结果与专项适配缺口，再用服务器的训练、归档、分析、干预吞吐分别估时。四张84GB卡的显存不能直接换算为这些异构作业的完成时间。

## 4. 重用什么，必须新增什么

同一个合法检查点可重用轨迹、内容探针和拟合中间量；L3、L4以及训练阶段分析尽量共享。自然内容分支、不同内部操作与不同恢复条件保持独立结果，不能合并后失去判别信息。所有保存检查点仍可回放。

改变训练梯度、训练读出、物理宽度/状态量、编码器或任务监督的配置按科学身份单独训练。特别是L3.2的N轴、L6.1/L6.2的学习规则，以及L5.4的实际模型修改，不能仅靠重分析已有检查点完成。

现有14共同分析模块是共享能力；原专项协议的适配、操作阶段、匹配控制与输出需要分别验收。已核查到现有selective_analysis主要处理focal源；非目标历史干预及其独立验证需要明确补充。恢复/reblocking、完整二值路径以及空间专项也不能由一个通用模块成功回执宣告全部完成。

## 5. 今晚的顺序与明天的交付

1. 核对全部层级及小节，审计现有结果和适配缺口；编译有来源的训练/分析依赖清单。

4. 冻结候选规则，再做留出条件和设计收益检验；不能在确认集反复选规则。
5. 截止时输出全层报告、原始证据索引、已执行/失败/待执行表和后续队列。未完成项不消失，也不因截止到来而标为完成。
