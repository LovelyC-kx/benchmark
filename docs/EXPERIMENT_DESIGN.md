# 从现有代码到全量实验的执行设计

当前执行顺序以[四阶段全量方案](FOUR_PHASE_EXECUTION_PLAN.md)为准。下文保留任务、模型和L1—L4共享模块的具体合同；原六层及专用小节由`all_layer_coverage.json`继续逐项覆盖。

本轮先把“发现现象—解释—检验—形成改动”接通，再根据可信结果组织论文。目标不是预设SNN优于所有模型，而是得到可迁移的能力判断和机制规律，并据此指定有效的模型/读出改动。

## 1. 一个实验的最小合同

`TaskSpec + ModelSpec + TrainSpec`决定训练ID。分析配置单独决定analysis ID；修改分析不重复计算模型数量。真实数据路径不是科学身份，规范manifest SHA才是。检查点包含原配置、实现SHA、完整权重、优化器、随机状态、轮次/样本游标、更新数、初始与当前参数SHA。

同一数据世界按 `(data_seed, split, scene_id, factor)`定位。样本前缀不随N或分块改变。任务真值、版本、噪声、来源与时间只进入分析；网络调用只接受 `x`。

### tagged世界中的四个容易混淆的量

| 量 | 代码位置 | 改变什么 | 配对约束 |
|---|---|---|---|
| 保持年龄 | `blank_delay`；T=当前写入步+1+blank | 当前写入之后的空白步数 | 底层内容、噪声、写入日程固定 |
| 物理内容维数 | `k`＋`physical_k` | 真正输入的内容坐标 | 固定底层维数=`sensory_dim`与投影；其余坐标置零 |
| 目标要求维数 | `k`＋`demand_only` | 输入全部内容，改变监督坐标 | 输入世界固定，损失mask改变 |
| 目标项目负荷 | `required_history` | H1…HL与C共同为监督目标 | 角色从合同推导，不能把H2永久当无关 |
| 后续写入数 | `extra_writes` | H1之后的其他历史写入 | 只在不会删掉被要求项目的条件使用 |
| 能量约定 | `raw/fixed_rms` | 保留原能量或缩放到共同期望总能量 | 缩放信号与噪声一起，不能暗中改变SNR |

默认投影是满秩正交列，底层维数与传感维数一致。它提供固定观察坐标，不人为制造投影瓶颈；帧编码器是否存在是另一项实验因素。

角色进一步落实到坐标：同一来源前k维被要求，其余维可能仍被输入但不被要求，或根本没有被写入。`requested_coordinate_indices`与`physical_coordinate_indices`分别登记，联合编码、擦除、ANOVA使用坐标角色；探针同时报告整来源与被要求坐标的恢复。符号答案用one-hot诊断目标，不能把任意类别编号大小当作语义距离。

## 2. L1：先确定任务到底要求什么

### 保留的任务与新协议

原10向量任务为repeat、stale、complement、order、interval、delay、xor、crosslag、drift、toy binary_adding。原6图像任务为repeat、complement、stale、misaligned、rain、cloud。分别运行原分类与连续目标，图像使用原生空间重建头。旧order/interval等不能仅凭名字变成已经证明顺序/度量时间必要的任务。

| 协议 | 当前实际输入/目标 | 默认及扫描 | 识别/分析重点 |
|---|---|---|---|
| G01 | 显式key/value/write/query；查询值回归/属性分类 | T128；items2/4/8/16，age8/16/32/64，writes0/4/16/32，拒绝不可行组合 | 年龄与写入分离；固定key接口容量16；查询目标写入步固定，所以它本身不能单独证明查询绑定能力 |
| G02 | write/overwrite/invalidate/query；最新或保护项目；无效类/有效位 | versions0/1/2/4，latest/protected，失效概率0/.25/1 | 最新、旧版本与其他项目分开；固定version_slots，以其他key写入填充，事件总量匹配；原生目标包含失效语义 |
| G03 | K≥4事件的排列，末尾随机事件对查询 | K4/8/16；符号ID与时刻分开 | 相对顺序分类或秩差回归；事件集合相同而排列不同，不靠固定首事件即可覆盖全部问题 |
| G04 | 随机事件位置/查询对，离散或不规则物理时钟 | 有符号事件索引用于找两端；目标为间隔大小，分类比较声明阈值 | 不是顺序正负分类；时钟按已知固定单位归一，不能用未来实测终点归一；物理时间隐藏时拒绝冒充可识别任务 |
| G05 | z+噪声；独立观测、单观测重复、粗测量因果保持 | T32；measurements1/2/4/8/16/32 | 新证据数与计算步分开；高斯后验风险作解析参照；重复分支只有1份独立测量 |
| G06 | 目标与干扰的高斯正弦/余弦系数、噪声和合法目标频率 | 频率1/2/5/10，交叉组合 | 目标波形或系数/属性；频带重叠时标注不可分离情形；不是把频谱分类分数改称记忆容量 |
| G07 | 四波段同源局部观测，静态内容，H属性分类/图像恢复 | T6，H≥8且偶数 | 当前可见、仅历史可见、全程未见分区；分类与细节恢复来自同一世界；不是照片语义标签 |
| G08 | 当前局部更新与旧内容；目标时刻干净图/属性 | T6，四区域；C/H/changed/U可追溯 | 更新区域、仍有效历史、旧H及旧更新内容；真实运动与图像素材扩展保留清单接口 |
| G09 | 同一细网格OU过程上的新采样、重复、因果保持、延迟线性插值 | T16/32/64；raw4/8/16 | 固定物理窗口与终点；插值记录右支持点可用时间，声明最终deadline协议，不能算作名义时刻在线模型 |

另有官方九标记Binary Adding的平衡条件生成参照、Copy Memory、单/多查询MQAR参照。多查询使用查询位置掩码损失；它们不是作者有限语料的逐比特复现。原Zoology/MAD/NeuroGym等来源继续作为协议对照。

### 同权限观察参照

`task_controls`在probe_train训练、probe_val选择原生损失线性读出，评价current、recent4、unordered_sum、ordered_trajectory。分类用真正类别，重建保留空间目标。超出预算时使用固定无标签投影并记录维数。

无序sum只是一种集合摘要；它失败不能证明所有无序算法失败。合成任务的可识别性结论优先由同观测异目标配对或解析条件给出。真实数据用这些参照寻找经验性短路，保留来源组与目标权限。

## 3. L2：相同任务上究竟改变了什么机制

### 单元方程与命名

设有效输入为I，上一膜状态v，衰减β，阈值θ；`pre=βv+I`，事件`s=1[pre≥θ]`。以下是本项目参考单元，不以近似公式宣称官方复现。

| 单元 | 状态/输出变化 |
|---|---|
| lif_hard | post=pre(1−r·s)，output=s |
| lif_soft | post=pre−rθs，output=s |
| threshold | post=pre，output=s；仍有跨步积累 |
| if_hard | β=1的硬重置 |
| plif_ref | 标量β=sigmoid(rawβ)可学习 |
| hetero_lif | 各通道β可学习且异质初始化 |
| alif_ref | θ_eff=θ+a；a_next=ρa+g·s |
| adlif_ref | I_eff=I−a；a_next=ρa+g·pre+0.1s |
| two_state_ref | syn_next=ρsyn+I；膜输入=(1−ρ)syn_next |
| continuous | output=post=pre；保留时间递归 |
| tanh | output=post=tanh(pre) |
| analog_hard_ref | output=pre，post仍硬重置；模拟幅值与reset分离对照 |

`r=reset_strength`。`full/detach/notd`分别是完整信用、仅切断时间梯度、真正删除每步历史状态；detach与full前向应一致，notd应改变前向。四种SG、reset梯度、衰减、输入增益、归一与编码都有显式配置。

### 骨架与完整状态

8参考骨架为MLP、recurrent MLP、causal temporal conv、CNN1D、CNN2D、小宽度SEW-ResNet18骨架、逐帧spike spatial attention、两尺度U-Net。空间重建仅cnn2d/unet，连续对照可用ConvGRU；没有定义的trajectory空间头直接拒绝。

v0.3公共工厂包含14种可注入骨架与18种连续参照，新增TCN、位置Transformer/Conformer、S4D/LRU/Mamba-style、残差/VGG及空间/视频参照，逐项见[扩展说明](REAL_DATA_AND_MODEL_EXPANSION.md)。旧screen/full等profile保持原八骨架/五连续控制口径，新expanded选择32种模型的兼容子集。实际状态与参数单独统计；固定骨架的depth仍用兼容哨兵2，真正支持的深度扫描以ModelSpec.validate为准，不能把同一固定网络重复计成不同深度。

帧MLP编码器无跨步状态；tagged及key/write协议用显式valid门保持空白为零。`encoder=none/auto`可对照；导出实际已训练encoder后用SHA锁定并冻结，可进一步拆分共同观察映射与核心机制。不同单元的同路径同形状参数使用相同初始值，数据和样本顺序也配对。

当前screen/full的SNN锚点采用post访问，服务内部状态研究；不能把它悄悄计作spike-only部署对标。原生发放输出、pre与post训练应按权限分别比较。`examples/phase_neuron_grid.json`列出全部12单元×3观察相位×5读出，可用sweep对明确任务/骨架展开；paired预设再检验部分关键机制组合。连续baseline的output是其连续隐状态接口。

快照包含所有cell状态、辅助状态、显式延迟/递归缓存、attention前缀、读出累计、事件控制和流游标。回放测试验证后缀预测一致。资源计数涵盖这些运行状态，不宣称测到了异步硬件能耗。

### 机制诊断

`working_point`报告校准流中的电流、margin、pre/post、真实emit/reset事件与辅助状态分布。`mechanism`把emit、reset、aux分支分别置零，其他分支保持自然；连续模型明确没有这些事件分支。

`realized_current_accounting`按真实reset门验证膜状态展开。硬重置参照为：

$$v_T=\sum_{k=1}^T I_k\beta^{T-k}\prod_{j=k}^T(1-rs_j).$$

软重置分别保留输入和阈值扣减项。这是实现核对和“有效电流沿实际路径存活多久”的诊断；门取决于输入，不能把展开系数直接称为独立因果贡献。辅助状态的作用要结合a/syn探针与独立干预。

## 4. L3：保留的内容怎样组织

| 模块 | 估计/拟合 | 必须同时保留的对照 | 输出与用途 |
|---|---|---|---|
| 线性探针 | 每站点/载体/时间，fit标准化，独立选择ridge | 负R²、未到达/未出现source比例、标签打乱 | 按每个来源的恢复轨迹；不能把总平均遮蔽角色差异 |
| 非线性参照 | 最后输出载体上MLP，用选择集选训练步 | 容量/训练步、独立评价 | 检查线性不可读是否来自读出族；失败不证明信息不存在 |
| 联合编码 | 同时由focal/cotarget/unrequested真值预测表示 | 设计秩、残差、每个有限样本交叉项 | 区分统计叠加与几何重合；协方差恒等式验证 |
| 子空间 | 拟合编码矩阵的数值支撑 | 空子空间、强制交集、Haar重合基准 | 看可读方向是否挤在一起；不能从重合单独推出有害干扰 |
| grouped ANOVA | tagged产品分布的完整pick-freeze lattice | 噪声独立组、负估计不裁掉、闭合残差 | 输出非线性主效应与组间交互；固定日程条件下估计，不冒充真实数据全分解 |
| 时间几何 | TGM；raw/center/orthogonal/similarity/affine对齐 | 映射无标签、方向、秩与参数预算 | 区分保持、坐标漂移和读出失配；同一reader跨时间迁移 |
| 通信 | 实际module consumer输入边、cell真实输出 | 接收端、时刻、保持的其他分支 | 通信局部瓶颈与状态储存区分；没有把任意网络当两层串联 |
| 理论参照 | 命名协方差几何、交叉拟合任务谱、连续混合矩学习曲线 | 独立矩池、奇异状态、signed估计、真实Hebbian读出曲线 | 检查哪些几何量能解释具体有限读出；不是训练好SNN的普适容量定理 |

数学内核保留原参考的Gaussian、finite-p、任务结构及更高阶控制代码。当前公共runner接入的是表中子集，其他专用检验仍按旧来源执行；不自动把19份数学文件的存在等同于19项已完成的真实模型证据。

对于高维真实重建，完整图像始终用于原生风险/区域/频率分析；表示诊断另用分来源、无标签、固定坐标预算，并在报告中记录目标坐标。像素可作为明确的分析目标，但不能直接改名为独立潜变量。

`oracles.py`另给任务侧观察参照：tagged的Gaussian后验MSE/符号误差、G05新证据/重复的后验风险、G06频带重叠的线性Gaussian风险、G09底层测量的Kalman参照，以及合成空间全程未见独立纹理的解析区域风险。这些解析量服务于区分观察不可识别与模型失败，不是有限状态SNN的性能定理；完整真实数据没有被强套这些独立性假设。

## 5. L4：从“可读”走向“实际利用与可改变”

### 权限与读出

`access`在相同检查点比较最后输出的last/mean/sum/trajectory、pre/post/a/syn以及多站点捕获状态的独立读出。原生头的原任务风险始终单独保留。新读出拟合预算相同，并记录完整维数与压缩；不能把新读出成绩当作原头自然使用证据，也不能从非单调有限分数硬凑风险差分定理。

### 选择性操作与验证

`selective`在probe_train拟合局部连续状态的LEACE/orthogonal操作，随后用全新verification_train/verification_val训练和选择验证探针，最后在独立评价流记录来源恢复与原任务损失。

对照包括相同移除秩的随机投影、相同逐场景位移范数的随机方向。记录被操作的真实状态键、坐标、时刻、拟合残差及其他任务角色的代价。辅助状态、缓存、读出和已发出的消息未被悄悄算作一起删除。二值消息不应用任意连续擦除矩阵；真实消息/边另走合法操作。

### 状态、消息、边分开

`interventions`对单站点做state、message、二者同时三种零化。state在步后改递归状态，message在消费者之前改模块输出。`communication`只改声明的单消费者输入，残差其他路径继续运行。零化属于诊断分布改变，需要与来源替换、拟合操作及随机对照合看。

完整任意图的最小cut/所有非module张量分支还需要专门adapter；当前输出明确列出实际站点，不能据此宣称穷尽了全图因果通路。

### 四组恢复

tagged世界固定一个任务要求来源、第一时间状态站点与该来源写入时刻。损伤是IID替换该世界来源，同时把评价目标固定为原目标。获得成对clean/damaged自然状态后，构造相同加性局部校正Δ，四组分别为clean、damage、clean+Δ、damage+Δ。

输出R00/R10/R01/R11、damage、rescue、patch-only、风险交互、输出Ω及平方风险精确恒等式残差。恢复比只在预设damage>.01时定义，不裁到[0,1]。这是成对干净状态oracle，属于机制上界诊断，不能当作可部署修复算法。真实数据与空间损伤尚无同等精确renderer时写`not_applicable`。

### 重建的独立分析

保留逐场景full、C、H、全程未见、变化区域及可选mask的损失和有效样本数；不把空区域记0。原始输出和[0,1]裁剪输出分开，报告越界率。DCT保留区域低/高频交叉项和Parseval残差；多波段给SAM与有效像素数。`PSNR(mean MSE)`与`mean(scene PSNR)`区别登记。

## 6. 全量运行的组织

| 阶段 | 必须产物 | 扩展依据 |
|---|---|---|
| 工程验收 | CPU测试、GPU smoke、canonical文件校验、实际参数更新 | 所有所需任务形状/单元/骨架可运行 |
| screen | 原任务与协议锚点、跨单元/骨架、多种子 | 覆盖能力/目标/骨架；不依据结果悄悄删失败项 |
| full | 年龄、需求、物理内容、负荷、写入、版本、频谱、采样轴 | 先配对控制，再解释大交互；所有不可行组合留原因 |
| paired | β/reset/观察相位/读出族等机制组合 | 区分前向动力学与读出/学习因素 |
| learning | SG、reset梯度、时间梯度和编码 | 用训练进度checkpoint追踪表征形成，不只看终点 |
| 确认 | 冻结发现后指定新seed/来源/条件 | 评价事先写出的方向、转折点和改进预测 |
| 最终审计 | 独立audit一次性读取、锁定指标族与报告 | 防止探索性多次试探变为虚假确认 |

默认epochs60、AdamW、batch128只是可执行起点，不能作为所有模型已经公平调优的证据。正式比较需要每骨架/单元相同的验证预算；`sweep`可展开width、LR、SG等实际字段。参数、状态、训练步、样本与计算权限分别报告；固定宽度不等于固定参数量。

G02的全失效/无失效、未要求坐标、无reset单元的reset参数等包含低熵或无效作用轴，应保留为负向对照，不能将相同前向行为硬计成独立机制发现。原生目标是否需要历史，仍先看L1合同和观察参照。

## 7. 怎样从现象走向论文贡献

| 候选发现 | 最少需要排除什么 | 转为有用改进的路线 |
|---|---|---|
| 历史可读但原头不用 | 探针拟合预算、观察相位、轨迹读出额外缓存 | 指定受限读出/内容访问改动，预测哪些任务改善及哪些无效 |
| 更强保持反而损伤当前任务 | 新证据量、能量、旧版本与共目标区别 | 按角色保护状态或改变reset；同时检验当前/历史/其他项目的代价 |
| a/syn保留而v不保留 | 相同观察坐标、完整状态与辅助读出权限 | 建议载体访问或局部修复，并在新条件验证其增益 |
| 时间对齐恢复跨时刻读出 | 映射标签泄漏、affine容量、rank不充分 | 指定读出稳定性/对齐约束，再做事先指定的迁移预测 |

| 类别高分而细节恢复失败 | 目标要求、空间头、损失mask、当前线索 | 用同源目标证明能力差别，给后继架构选择状态/读出预算的依据 |
