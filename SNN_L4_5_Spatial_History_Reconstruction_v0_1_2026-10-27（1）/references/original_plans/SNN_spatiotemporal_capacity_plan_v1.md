# SNN 时空容量：数据与执行计划 v1

日期：2026-09-18。目标：以可证伪机制与预测能力为核心，争取 NeurIPS / Nature Machine Intelligence。本文是拟执行方案，不是实验结果或录用保证。

## 1. 已作决定

核心问题：固定状态和读出资源时，当前内容、历史内容与跨时间关系计算如何分配可用容量？任务关系何时产生竞争、何时允许协同，阈值/reset 又改变了什么？

数据顺序：受控向量校准 → 可控图像序列 → Diving48 V2 → EarthNet2021/U-TILISE 重建协议 → 有明确跨域检验问题时再上 AllClear。SSV2 仅在需要直接验证 STSep 的原始现象时追加关键配置；SSV2-mini 只作为开发子集。

第一阶段固定因果输入：预测时只能访问当前及过去；一个观测帧对应一次更新。若后续增加每帧内部 simulation steps，单独记账，不与观测帧数混用。离线双向重建放在独立协议中。

## 2. 当前代码核验

核验仓库：LovelyC-kx/historySNN，分支 claude/cool-volta-d7hhz3，提交 a68337570634ffbcc29348b34baf825188496230。本次读取了 synthetic.py、neurons.py、sew_resnet.py、合成训练脚本、合成结果表、Diving48/SSV2-mini 配置与标注脚本；没有运行训练，也没有改动远程仓库。

- synthetic.py 已有 32×32、12 类运动渲染器，但只返回 clip、label、idx；未返回潜变量、无污染目标、重复污染组。
- 现有生成器的增长/收缩会改变大小分布，平移会改变位置分布，轨道与平移的空间统计也不同。不能凭“外观随机”断言任意单帧或无序帧集合都只能达到随机水平。
- 已保存合成表确有 vanilla 42.7、NS5 27.7、rNS2 87.0、STSep 97.0 的 Top-1；这些是旧协议下的观察，不能直接证明容量竞争或优化伪影。
- synthetic/base.yaml 默认仅 1,200 train、300 val、6 epoch；结果表写的是 20 epoch。正式运行须保存最终合并后的完整配置，不能从默认配置反推运行设置。
- neurons.py 默认 shared：历史系数与输入增益均为 1/tau；eq2：历史系数 1−1/tau，输入增益 1/tau。shared 是仓库为解释论文 τ=1 歧义采用的实现选择，不是已核实的作者官方实现。
- record 中 membrane 是计算 spike 时的发放前电位。下一步重置通过上一 spike 实现。后续额外记录输入电流及等效重置后状态。
- sew_resnet.py 最终对逐帧 logits 求均值。这允许全 NS 模型使用无序帧集合的信息，不等价于只看最后一帧。
- build_annotations.py 把 Diving48_V2_test.json 写成 val.txt。新研究从官方 train 中另外划 development validation；官方 test 不用于超参数与 epoch 选择。若旧实验已反复用过 test，要披露，并用未使用的外部数据增强独立验证。
- SSV2-mini 是脚本按 seed 随机抽类别和每类样本构建的子集，不应称作统一官方 benchmark。
- 仓库存在输入差分/分支实验载体，但本计划新增的独立历史系数、软 reset、连续状态基线和容量测量尚未实现。

## 3. 数据选择及职责

| 数据 | 角色 | 何时使用 | 边界 |
|---|---|---|---|
| 独立可控向量 | 校准容量/读出公式和阈值对照 | 立即 | 只是校准，不能代替图像结论 |
| 自建可控图像序列 | 潜变量、任务关系、污染的干预 | 核心主战场 | 明示人为生成；分离统计机制与渲染偏差 |
| Diving48 V2 | 检验真实视频中的状态配置预测 | 合成机制成立后 | 没有完整潜变量真值，不强行套潜变量几何公式 |
| EarthNet2021 + U-TILISE 协议 | 真实地表图像、已知人工遮挡目标 | 重建首选 | 受控缺失重建不等于真实云去除；筛选晴空会改变数据分布 |
| AllClear | 地理与真实观测条件的外部检验 | 后期按 ROI 子集起步 | 不能把临近日期参考当同一时刻无误差真值 |
| SSV2 / 自定义 mini | STSep 原现象对照 | 有必要再加 | mini 结果不等价于完整数据集复现 |

Diving48 使用 V2 标注。已有本地副本先清点视频数、类分布、坏视频、帧数与标注覆盖率，不凭文件夹大小认定下载完整。开发 train/val 从官方 train 划分，优先按原始视频来源分组，无法恢复可靠来源时记录限制。

EarthNet2021 在 U-TILISE 文档中为 30 帧、128×128、B2/B3/B4/B8 四波段、名义五天网格。U-TILISE 筛掉有缺失的帧后，保留下来的有效观测间隔会不均匀；必须使用 position_days。作者提供约 14 GB 的 iid test 演示数据和预训练模型，此包只用于复现评估/检查流程，不能当开发训练集。开发需要官方 train 划出的独立 train/val。

AllClear 是 NeurIPS 2024 Datasets and Benchmarks 数据工作。后期先使用 Sentinel-2 单模态以控制问题，再另列 SAR 扩展；不是现在就下载全量或加入所有卫星。

## 4. 可控图像数据 v1

共用渲染器，初始 T=8，RGB 32×32。先以颜色/纹理块、简单几何图形编码因子，随后用 64×64 和不同纹理族检查渲染依赖。独立内容负荷通过潜变量个数控制；总亮度、对比度和占用面积尽量匹配，避免把能量变化当容量变化。

### A. 当前与历史独立需求

在 t−L 呈现历史因子 b，在 t 呈现独立的当前因子 a，中间加入无关干扰帧。两组目标都要恢复，损失按组内维数归一化，防止因子多的一组仅因 loss 项多而支配训练。使用独立、标准化的连续因子，或按独立平衡比特定义正交目标。

第一轮：历史维数 d_h=4、L=4、T=8；当前维数 d_c∈{2,8}。可诊断时间模块只有 n=8 个持续状态，前置空间编码器无跨帧状态，所有读出经过共同瓶颈，不能跳接原图或历史。这样总因子数覆盖低于/高于状态维数两侧。随后扩展 n∈{4,8,16}、L∈{1,2,4}。

先用固定编码器/解析输入隔离动力学，再以相同架构端到端训练。分别报告每个表示对象的当前和历史测试 NMSE、可读容量；不把跨时间串联状态计入同一个 n 维界。

### B. 历史是同一内容的重复观测

同一干净图像在多个时刻受到独立遮挡或噪声，目标是恢复其内容。固定当前帧遮挡，改变历史有效覆盖率和污染相关性。让更多可靠历史有机会提供增益，但不预定任意 SNN 必须获益。

第一版使用规则/随机块 mask；后续使用真实云形状及半透明污染。保存干净目标和精确 mask。增加不同场景的错误历史作为负对照，但不得解释为纯“记忆强度”干预。随后加入真实内容变化，用于测试历史过时的代价。

### C. 跨时间关系

C1：两个平衡独立属性分别在过去和当前出现，判断是否相同。任一单帧的类别条件分布相同，但无序集合可能足以解决它；因此 C1 测关系整合，不被称为严格顺序任务。

C2：相同帧集合构造 A→B 与 B→A，末尾追加完全相同的查询帧，目标判断顺序。反事实对属于同一数据 split；同一 multiset、同样噪声帧按顺序置换，避免噪声泄露标签。无时间位置编码的逐帧处理+对称聚合输出应相同；这是排查顺序捷径的强控制。

真实移动形状序列仍可使用，但要让逆序对共享轨迹与每帧图像集合，并匹配边界、速度、大小和标签统计。不要通过换标签后独立重采样生成所谓配对数据。

## 5. 数据接口与划分

建议新增 stsep/data/capacity_synthetic.py，保持旧 synthetic.py 用于旧结果回溯。新增文件均为建议，尚未修改仓库。

每个样本至少包含：frames、clean_target（重建任务）、targets_current、targets_history、target_relation、nuisance_parameters、masks、timestamps、scene_id、pair_id、repeat_id、generator_version、seed。

拟定开发规模：每个任务族 10,000 train / 2,000 val / 2,000 test 个底层场景；数据生成成本低时训练场景可增大。烟雾检查用 256/64，不算正式结论。所有反事实对、污染重复、同底图增强随 scene_id/pair_id 一起划分，禁止先生成变体再随机分割。

ID 测试用新场景和新 seed；OOD 分别保留未见纹理族、较长延迟或较强污染，单独改变一个分布因素。不能只换 seed 就称作 OOD。

额外建立表示分析面板：从独立场景中取 256 个场景，每个生成 8 个污染重复，固定内容和轨迹。用于估计条件变异；8 次重复只是初始预算，检查稳定性后再扩大。模型确定性输出不应人为称作“神经随机噪声”。

## 6. 必须先通过的数据控制

1. 最后一帧/指定单帧 baseline：在设计为无历史捷径的历史/关系标签上，标签条件分布必须匹配。观察到超出预设容差的可预测性时，先解释数据，不能直接声称时间建模。
2. C2 的配对无序帧集合完全相同；无时序模块、无位置编码的对称聚合应产生相同预测。该结构性检查比“某个弱模型没学会”更强。
3. 历史变量与当前变量独立；大小、位置、边界裁切、噪声与标签的关系可审计。
4. 原始输入/完整序列的高容量参考解码器能完成任务。参考不能完成时先检查生成任务是否可识别。
5. 时间增强先核查标签：逆序、水平翻转可能改变方向标签；整个 clip 的几何增强应一致。
6. 评估始终使用 eval 模式；因果实验避免跨时间统计泄漏。逐时刻独立归一化或固定统计优先；联合 T/B 的训练 BatchNorm 不用于声称严格在线因果机制。

## 7. 模型、资源和读出协议

第一轮只做小型图像编码器+显式 n 维时间模块。前置编码器保留空间位置，不直接全局平均掉待解码的位置/纹理因子。

LIF 参数写成 v_pre[t]=alpha*h_post[t−1]+g*I[t]，再阈值并重置。alpha 与 g 独立，第一轮固定 g=1；alpha∈{0,0.5,0.9}。改变 alpha 引起的幅值变化先作为机制的一部分记录，再追加幅值/发放率匹配控制，不称扫描本身已完全隔离历史作用。

第一轮预算：A 任务，2 个当前负荷 × 3 个 alpha × 3 个训练 seed = 18 个训练。相同数据、批次次序和对应初始化用于配对比较。它用于决定下一步，不能仅凭这 18 个点宣布容量边界。发现值得追踪的区域后，扩展状态维数、任务权重（如 0.25/0.5/0.75）、训练预算与独立 seed。

随后追加连续状态 RNN/泄漏模型作为读出与阈值机制对照；连续对照从开始就在研究设计中，避免只凭 SNN 内部比较声称特有性。再扩展到 LIF/ALIF 和层级网络。ALIF 的额外适应状态要计入预算。

真实视频复用 vanilla、NS2、rNS2、STSep、STSep-wo-diff，并补 plain difference baseline。每种设置报告参数量、持续状态/缓存标量数与精度、峰值显存、推理时间、运算统计。GPU 显存/速度不能直接等同神经形态能耗。SSM/RNN 的严格匹配对照在核心规律稳定后扩大。

主容量读出只访问一个指定时刻的共同表示，先测发放前膜电位，再单列重置后状态和当前 spike；整个 spike sequence 另列，不与单时刻维度界混合。真实任务的 temporal mean、差分缓存、跳接所提供的历史访问都要说明。

probe 训练、调参、测试三者分开；岭回归正则只在 val 选择。主报告测试 NMSE/R²（负 R² 不截成零美化），同时展示单因子分数和组均值。只有正交标准化目标才按 IPC 定义求和，其他情况报告任务性能，不套容量和上界。

最优线性读出是参照；Hebbian 是受限读出对照；小 MLP 检查非线性可读性。MLP 恢复表现支持读出限制，但失败不能证明信息不存在。四个 Wakhloo 几何量先校准后使用，不能用它们不变来排除一切表示机制。

## 8. 记录与统计

每轮保存 git SHA、最终配置、数据 manifest/hash、随机种子、实际样本量、优化步数、checkpoint、训练/验证曲线、计时和资源统计。

表示只在固定分析集、选定层和时间上采集 I、v_pre、s、h_post，另存阈值附近质量、发放率及梯度范数。不要全量保存所有训练 batch 的高维激活。高维线性 probe 可用固定子采样/投影并检验投影维数敏感性；逐单元阈值研究保留原始坐标。

3 seed 用于筛查，关键结论追加到至少 5 个独立训练 seed 作为起点；最终数量根据效应与不确定性决定，不以固定 seed 数保证显著。报告配对效应和区间，训练重复与数据重复分别汇报。视频/场景/ROI 是评估重采样单位，不能把每帧或每像素当独立实验重复。

## 9. 分阶段推进与验收

| 阶段 | 交付物 | 进入下一阶段的条件 |
|---|---|---|
| P0 实现/协议审计 | 固定提交、数据清单、动力学公式、train/val/test 划分 | τ 语义、时间访问和评估集用途无歧义 |
| P1 数据+测量校准 | 三族数据样例、潜变量 manifest、解析基线和捷径检查 | 对照行为符合生成机制；指标能恢复已知答案 |
| P2 小模型初筛 | A 任务 18-run、当前/历史曲线、连续状态对照 | 现象稳定且能与训练不足、输入尺度效应区分 |
| P3 理论与干预 | B/C 任务、状态预算扫描、具体定量预测及盲测设置 | 能预测未用于建立规律的设置；分离失败边界明确 |
| P4 真实视频 | Diving48 V2 关键配置与控制 | 合成得到的至少一条预先预测可迁移；不强迫所有现象复现 |
| P5 图像重建 | EarthNet/U-TILISE 基线及受控替换 | 相同数据和可访问时相下改善性能或资源效率，变化不被抹平 |
| P6 外部验证 | AllClear 或跨架构检验 | 回答明确的新泛化问题，避免仅增加排行榜 |

P2 失败时：若所有模型都学不会，检查数据/优化；若所有指标都饱和，提高独立内容负荷或缩小实际瓶颈；若当前与历史共同提升，先研究容量利用不足，不强行写竞争；若只有 Hebbian 降低，聚焦受限读出条件；若只在某渲染器成立，增加渲染控制后再下结论。

## 10. 重建协议

保留 U-TILISE 的原始 seq-to-seq 复现作参考；主因果问题另定义过去/当前输入→当前目标，ANN attention 与 SNN 都使用同样输入和时间信息，避免把双向离线模型与在线模型直接排名。

先让编码器和解码器保持一致，仅替换 temporal module。分别做相同冻结表示的机制对照、相同训练预算的端到端对照，防止把冻结不适配造成的性能差当架构限制。四波段起步；SAR 是后续单独因素。

指标：全图及遮挡区域 RMSE/PSNR/SSIM，光谱角 SAM，未遮挡区域保真度；在有可靠真值时增加真实变化区域误差。不能只报全图 PSNR，它可能被大面积未遮挡区域主导。

真实图像选择晴空观测，再人工遮挡用于精确目标评估；在真实云层下没有同刻真值的像素，不宣称已经直接测得恢复误差。跨日期参考须报告时间差与变化混淆。训练验证测试按 ROI/地理区域分组，所有切块和时间窗口跟随所属区域，兼顾邻近区域泄漏。
